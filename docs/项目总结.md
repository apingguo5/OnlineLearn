# OnlineLearn 在线学习平台 — 项目总结

## 一、项目概述

**OnlineLearn** 是一个面向在线教育场景的 Web 应用平台，采用前后端分离架构，支持 **管理员、教师、学生** 三种角色，提供课程管理、视频学习、作业管理、在线练习、问答互动、考试测评等核心功能，覆盖完整的教学闭环。

| 模块 | 技术栈 | 端口 |
|------|--------|------|
| 前端 | Vue 2 + Element UI | 9252 |
| 后端 | Spring Boot 2.5.6 + MyBatis-Plus 3.4.0 | 9251 |
| 数据库 | MySQL 5.7+ / 8.0 | 3306 |

### 3.2 后端分层设计

采用经典的三层架构模式：

```
Controller (接收请求、返回响应)
    ↓ 调用
Service 接口 → ServiceImpl 实现 (业务逻辑)
    ↓ 调用
Dao/Mapper (MyBatis-Plus，数据访问)
    ↓
Entity (ORM 映射)
```

- **Controller 层**：共 19+ 个 REST 控制器，统一使用 `Result` 封装响应，`@CrossOrigin` 支持跨域
- **Service 层**：接口与实现分离，便于扩展与测试
- **Dao 层**：基于 MyBatis-Plus 的 BaseMapper，配合 XML 文件编写复杂 SQL
- **Entity 层**：与数据库表一一对应，使用 `@TableName`、`@TableId` 等注解

### 3.3 前端架构设计

- **组件化开发**：按功能模块划分视图组件，复用 Element UI 组件
- **路由分离**：使用 Vue Router 管理多页面导航，含路由守卫
- **状态管理**：Vuex 集中管理全局状态（如作业信息）
- **API 层封装**：统一的 Axios 实例，请求/响应拦截器
- **三种角色独立视图**：管理员后台、教师端、学生端各有独立的视图和路由

## 四、数据库设计

### 4.1 核心表关系

```
role (角色)
  ↑
user_role ─→ user (用户) ─→ user_class ─→ class (班级)
                                     ↑
                                course_chapter (课程章节)
                                     ↑
                              course_resource (课程资源)
                                     ↑
                              video_watch_record (观看记录)
```

### 4.2 表清单（16+ 张表）

| 表名 | 说明 | 核心字段 |
|------|------|----------|
| user | 用户表 | account, password, user_name, phone, sex |
| role | 角色表 | role_name (admin/teacher/student), description |
| user_role | 用户角色关联表 | user_id, role_id (多对多) |
| class | 班级表 | class_name, course_id, user_id (班主任) |
| user_class | 用户班级关联表 | user_id, class_id (多对多) |
| course | 课程表 | course_name, description, creator_id, status |
| course_chapter | 课程章节表 | course_id, chapter_name, parent_id, sort_order |
| course_resource | 课程资源表 | course_id, resource_type, file_url, chapter_id |
| homework | 作业表 | title, content, answer, creator, class_id |
| user_do_homework | 用户作业提交表 | user_id, homework_id, score, content |
| exercises | 练习题表 | title, content, answer, creator, class_id |
| user_do_exercise | 用户做题记录表 | user_id, exercises_id, answer, score |
| knowledge_point | 知识点表 | title, content (Markdown), creator, class_id |
| ask_questions | 问答表 | sender, content, recipient, reply, status |
| applicant | 入班申请表 | user_id, class_id, status |
| video_watch_record | 视频观看记录表 | user_id, resource_id, watch_seconds, is_finished |
| exam_paper | 试卷表 | title, paper_type, course_id, total_score, status |
| question | 题目表 | question_type, stem, options, answer, score |
| exam_paper_question | 试卷题目关联表 | paper_id, question_id, sort_order, score |
| student_answer_record | 学生答题记录表 | paper_id, question_id, student_id, answer, score |

### 4.3 设计特点

- **外键约束**：使用 InnoDB 引擎，通过外键保证数据参照完整性
- **索引优化**：为经常查询的字段（如 course_id, user_id, status, create_time）建立索引，包含联合索引
- **字符集**：统一使用 `utf8mb4`，支持 emoji 和生僻字
- **自增主键**：统一使用 `INT UNSIGNED AUTO_INCREMENT` 作为主键
- **状态管理**：大量使用 `tinyint` 状态字段（如 status: 0-禁用, 1-启用）

## 五、功能模块设计

### 5.1 角色系统

| 角色 | 权限范围 | 主要功能 |
|------|----------|----------|
| 管理员 (admin) | 系统级 | 用户管理、班级管理、科目管理、知识点管理、全局作业管理 |
| 教师 (teacher) | 课程/班级级 | 课程创建、班级管理、作业发布批改、题库管理、试卷出题、成绩管理、问答交流 |
| 学生 (student) | 个人级 | 课程学习、视频观看、作业提交、在线练习、问答提问、查看成绩 |

### 5.2 核心功能模块

#### 5.2.1 用户认证与权限

- **登录**：账号密码登录，支持 MD5 加密与明文双重兼容验证
- **注册**：支持学生/教师在线注册，选择角色和班级
- **权限控制**：通过 `user_role` 关联表实现角色划分，前端路由守卫控制页面访问

#### 5.2.2 课程管理

- 教师可创建课程、管理章节（支持树形结构、拖拽排序）
- 支持章节目录的增删改查，含父章节（parentId）关联
- 课程资源管理：上传视频、文档等资源，关联到具体章节
- 课程文件系统扫描：自动识别文件目录结构生成课程大纲

#### 5.2.3 视频学习

- 视频上传与管理（支持大文件，配置 1024GB 限制）
- 视频播放（基于 video.js / vue-video-player）
- 观看记录追踪（自动记录观看时长、进度、完成状态）
- 观看进度统计

#### 5.2.4 作业系统

- 教师发布作业（含标题、题目、参考答案、截止时间）
- 学生在线提交代码/文本作业
- 教师批改评分、写评语
- 查看未提交作业学生列表

#### 5.2.5 练习系统

- 教师创建练习题
- 学生在线作答
- 自动评分与参考答案展示

#### 5.2.6 考试测评

- 试卷管理：创建试卷、设置题型和分值
- 题库管理：单选、多选、判断、填空、文字题
- 学生在线考试：答题、暂存、提交
- 自动批改（客观题）+ 教师手动批改（主观题）
- 成绩统计与查看

#### 5.2.7 问答互动

- 学生可就课程内容提问
- 教师回复解答
- 状态追踪（已回复/未回复）

#### 5.2.8 知识点管理

- 管理员/教师维护知识点
- 支持 Markdown 富文本编辑

#### 5.2.9 班级管理与入班申请

- 教师/管理员创建班级
- 学生申请入班
- 教师审核申请

### 5.3 接口风格

- **RESTful API**：使用 `@RequestMapping` / `@PostMapping` / `@GetMapping` 等注解
- **统一响应格式**：`Result` 类封装 `{ code, resultData }`，code=200 成功，code=504 失败
- **跨域支持**：`@CrossOrigin` 注解全局开启
- **请求体**：POST 请求统一使用 `@RequestBody` 接收 JSON

## 六、设计思路与亮点

### 6.1 前后端分离架构

采用前后端完全分离的架构，前端 Vue 通过 Axios 调用后端 REST API，通过 `vue.config.js` 配置代理解决跨域问题。这种设计使得：
- 前后端可以独立开发、部署和扩展
- 后端 API 可被多个客户端复用（Web、移动端等）
- 前端可以灵活切换技术栈而不影响后端

### 6.2 分层解耦设计

后端采用经典的三层架构（Controller → Service → Dao），每一层职责明确：
- **Controller**：只负责参数校验和结果返回，不做业务逻辑
- **Service**：封装核心业务逻辑，支持事务管理
- **Dao**：专注数据访问，通过 MyBatis-Plus 简化 CRUD

### 6.3 数据驱动设计

所有业务功能围绕数据表设计展开，强调：
- **外键约束**保证数据一致性
- **索引优化**提升查询性能
- **状态字段**（如 status）管理业务状态流转
- **时间戳字段**（create_time, update_time）支持审计追踪

### 6.4 多角色权限体系

通过 `user_role` 关联表实现灵活的多对多角色分配，为后续细粒度权限扩展预留空间。前端通过路由守卫和条件渲染控制不同角色的界面展示。

### 6.5 统一异常处理

`GlobalExceptionHandler` 全局捕获异常，对常见数据库连接错误、表不存在、SQL 语法错误等给出友好的错误提示，避免暴露敏感信息。

### 6.6 学习行为追踪

视频观看记录系统追踪每个学生的学习行为：
- 记录观看秒数和总时长
- 标记是否完成观看
- 记录最后观看时间，支持断点续播

### 6.7 题库 + 试卷 + 考试体系

设计了完整的考试测评子系统：
- **题库**：独立于试卷，支持题目复用
- **试卷**：从题库选题组卷，支持排序和分值设定
- **答题记录**：记录学生每道题的答案，支持暂存和提交
- **批改**：客观题自动批改，主观题教师手动批改

### 6.8 兼容性设计

- **密码兼容**：同时支持 MD5 加密和明文密码验证，便于旧数据迁移
- **跨平台路径**：`PathUtils` 自动适配 Windows / Linux / macOS 文件路径

## 九、总结

OnlineLearn 在线学习平台是一款功能完整的在线教育系统，覆盖"教学-练习-考试-评价"全流程。项目采用 **Spring Boot + Vue 2 + MySQL** 的主流技术组合，前后端分离架构清晰，数据库设计规范，功能模块完整。

项目亮点包括：
1. **完整的教学闭环**：从课程创建、视频学习、作业提交到考试测评和学习追踪
2. **多角色权限管理**：管理员、教师、学生三种角色各司其职
3. **规范的分层架构**：后端三层架构职责清晰，易于维护和扩展
4. **丰富的学习工具**：Markdown 编辑器、代码高亮、视频播放器等
5. **学习行为追踪**：视频观看记录、作业完成状态、答题记录等
